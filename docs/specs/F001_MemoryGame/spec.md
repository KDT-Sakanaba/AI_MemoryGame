## 目的
Unity で神経衰弱（メモリーゲーム）を作る。プレイヤーがカードを2枚めくって、絵柄の一致を競うカードゲーム。

## ユーザー視点の動作
- ゲーム開始時、カードは裏面（絵柄が見えない）で盤面に並ぶ。
- プレイヤーはカードをクリックして1枚ずつ表にする。2枚目をめくったとき、一致していればその2枚は表のまま残り、一致しなければ裏に戻る。
- 全カードのペアが揃ったらゲーム終了し、結果（クリア）を表示する。

## 要件
- R1: 盤面はグリッド状に整列した 48 枚（6×8）のカードで構成される。絵柄は普通のトランプの12番まで（本来13番までだが1つ少ない＝Kなし）の4種類×12番＝48枚、各1枚。ペア判定は数字（番）のみで、同じ番の2枚がペア、計24ペア。
- R2: 開始時、カードの配置はランダム（シャッフル）。
- R3: 同時に表にできるのは最大2枚。2枚目をめくると自動で判定する。
- R4: 一致したペアは確定扱いとなり、以後めくれない。
- R5: 一致しなかった2枚は短時間（約1秒）表のまま見せてから裏に戻る。
- R6: 全ペア揃った時点でクリア表示（手数と経過時間）を出す。
- R7: カードの視覚状態（裏/表/確定）がプレイヤーから区別できる。
- R8: 手数（2枚をめくるごとに1回）と経過時間をカウントし、クリア時に表示する。
- R9: リプレイ（盤面をシャッフルし直して、手数・時間をリセットして再プレイ）できる。
- R10: カードは 3D（メッシュ/スプライト）で立体表現し、めくる動作は回転で表現する。

## 受け入れ条件
- AC-01: 実行すると盤面に48枚（6×8）のカードがグリッドで表示され、すべて裏面から始まる。
- AC-02: カードをクリック（タップ）すると表になり、2枚目でマッチ判定が行われる。
- AC-03: 不一致の2枚は約1秒表示された後、裏面に戻る。
- AC-04: 一致したペアは表のまま残り、再度クリックしても反応しない。
- AC-05: 全ペアが揃うとクリア状態が表示される。
- AC-06: 同一カードを2回連続でクリックしても2枚目として扱われない。

## 範囲
- 対象: Unity プロジェクト内のゲームロジック、盤面 UI、クリック入力、マッチ判定、クリア表示。
- 対象外: サウンド、BGM、セーブ/ハイスコア、複数人プレイ、アニメーションの凝った演出、モバイルビルド。
- 将来構想（本機能の範囲外）: キャラクターが歩いてカードを取り合う方式へ拡張する予定。現状はマウスクリックのみ。
